What this release holds, and what it does not

Everything on this page is read from the files the current release publishes under worldsindex/data/; nothing is fetched from a provider when you open it, and nothing about you is kept. Where a file is not published, the section says so. Counts are the builder's own; a declared source is not a query receipt, and a provider that answered is not thereby ingested.

Sources: the four denominators

Declared means the source is in the versioned source universe. Applicable means at least one object of this release states an identifier of the kind the source is keyed on. Executed means a bounded query, snapshot lookup or retrieval attempt happened for this release — not computable for sources that run only in the visitor's browser. Data-bearing means valid rows were retained for at least one object. A source can be declared and applicable and still carry nothing; the last-attempt column says why.

Provider monitor

The monitor checks every declared provider each hour and records what it answered. A failed required check quarantines the attempt: the last validated receipt stays in force and nothing from the failing attempt is promoted into the atlas. The provider's own error text is kept and shown here.

Identity

Objects are counted by identity state: canonical and resolved identities link their retained aliases into one object; ambiguous identities and unreviewed records stay separate until review resolves them. Membership in several catalogs is not independent confirmation.

Reading manifest.json…

Controversial, retracted and excluded objects

Objects a source flags as controversial, retracted or refuted, or dispositions as a false positive, and objects whose sources disagree on status. Each entry gives the reasons with the source record and the source's own status; nothing is hidden from the catalog because of it. The list is read only when you ask for it.
