CTAS in brief

Transient is CTAS’s operational umbrella for a public, time-dependent astronomical event or candidate: optical, high-energy, radio, neutrino, gravitational-wave, or multimessenger. Inclusion records a report; it does not confirm a discovery, physical class, host, or counterpart.

CTAS score is a 0–100 follow-up ordering aid. It is not a probability, confidence, or measure of scientific importance. Higher scores generally surface recent, brighter, information-poor, or multimessenger records that may benefit from attention sooner.

Learn how CTAS works, how the score is built, and what the catalog does not claim

What CTAS is

A public research catalog that combines rights-cleared alerts, follow-up evidence, positional context, and explicit provenance for researcher-led triage.

How a record moves

Public intake → rights screening → normalization → contextual searches → transparent priority calculation → sanitized static publication. Conflicts, retractions, provider failures, and insufficient-data states stay visible.

How the score is calculated

CTAS starts at 35, then applies bounded terms for recency, source-reported discovery magnitude, missing or conflicting classification, missing spectrum, observation age, retained quantitative coverage, and messenger diversity. Existing observation coverage reduces—not increases—the score. Retracted or bogus records score zero; results are clipped to 0–100. Every candidate shows its exact terms.

What CTAS does not do

CTAS does not control telescopes, submit observing requests, publish classifications, or turn a provider report into a discovery claim. A positional catalog match is not presented as a host association.

How it is built

Local Python services and scientific libraries ingest public records into a local database. A rights-screened static snapshot is checked for changes about every two minutes and published to GitHub Pages. No browser-side secret manager or private dashboard is required.

How to use it

Open any candidate from the stream, sky, or ranked catalog. Explore the retained data inside CTAS, then use clearly labeled links to visit the exact source record, provider query, downloadable artifact, or documentation when one is retained.

      Interpretation

      CTAS ranks public records for review; it does not establish discovery, scientific truth, calibrated classification accuracy, host identity, or observing priority for a facility.

      Provenance and rights

      Each retained record keeps its provider and available source link. Third-party data remain subject to their source terms and attribution requirements; this page does not apply a blanket new license to provider data.

      Automated snapshot checks

      The published report binds the static catalog, interface, source universe, shards, and validation results to exact checksums. The local publisher checks every 120 seconds while its Mac is awake, online, and the visible terminal loop is open. “Verified” means those automated integrity checks passed for that snapshot; it is not scientific certification or human peer review.

      Use and cite

      Cite CTAS as “Cowboy Transient Alert System (Jack McGuire), version 1.4.1,” include the catalog checksum and access date, and cite each original provider used in scientific work. Contact Jack for a project-specific citation.
