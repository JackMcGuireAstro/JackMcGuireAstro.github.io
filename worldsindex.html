Interactive atlas

Move from the whole sky to one retained claim.

WorldsIndex keeps an all-sky Hammer–Aitoff view, catalog status, discovery-method claims, identity state, and source membership connected to each object dossier.

Celestial sphere

Explore the catalog union on one sky

Filter by status, method, source, and discovery year; zoom, pan, choose from overlapping coordinate stacks, or use the complete keyboard-equivalent browser.

Object evidence

See the selected value and every alternative

Display values are deterministic evidence-fitness selections. Source-native measurements, uncertainty semantics, definitions, limits, conflicts, and withheld ties remain inspectable.

Compare & learn

Population plots that show what they leave out.

Compare two to six planets on period, radius, source-reported mass, minimum mass M sin(i), model-estimated mass, eccentricity, incident flux, and equilibrium temperature. Box-select the plot, share the URL, open any underlying dossier, and download the exact filtered projection.

Every chart reports plotted rows and exclusions for missing axes, limits, nonpositive logarithmic values, method, status, and year. The interface states plainly that a catalog projection is not a completeness-corrected population sample.

For scientists

Export, replay, and audit one evidence state.

Immutable evidence runs

A refresh seals a run-scoped dossier with source contracts, receipts, assertions, conflicts, selections, checksum, policy versions, and explicit replay grade. Export links no longer trigger an undeclared live query.

Analysis-ready formats

JSON preserves the full dossier. ECSV carries the assertion table and run identity. Multi-table VOTable carries assertions, receipts, selections, and conflicts with IVOA-oriented metadata.

Source-native products

MAST observation identifiers now traverse to public product manifests in bounded batches. Protected and unknown-rights products are excluded; provider links are retained without mirroring large files.

Versioned API

Object, evidence, source, method, coverage, immutable-run, and run-specific export routes are described by an OpenAPI document. The live service—not GitHub Pages—holds the database and secret-backed adapters.

Scientific boundary

“All” has a denominator.

WorldsIndex does not claim every exoplanet, every historical measurement, every private archive, or every future publication. It claims the validated records inside its versioned source universe, plus explicitly bounded live queries whose receipts and failure states are shown.

  • A catalog row is not independent confirmation.
  • An archive holding is not a planet detection.
  • Evidence confidence is a transparent fitness assessment, not the probability that a value is true.
  • Per-property display values can come from different solutions; they are not silently combined into density, composition, atmosphere, or habitability claims.
  • New global snapshots remain quarantined unless identity, counts, parser behavior, scientific invariants, tests, deterministic exports, and rollback checks pass.
