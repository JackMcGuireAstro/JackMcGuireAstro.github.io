Cone search

Every CTAS transient and WorldsIndex planet or candidate within a radius of a position, from a sky index the deployment builds from the public releases. Download the result as a VOTable (the IVOA Simple Cone Search response form) or CSV.

The search runs in your browser: it fetches only the index cells around the position (HEALPix order 2, NESTED) and measures every separation exactly. A script can do the same with the files under tools/data/cone/ (see the manifest); a server-side Simple Cone Search endpoint is not offered.

Position

Catalogs

Radius up to 10 degrees. Positions in ICRS, decimal degrees or sexagesimal (hours for RA). The link of this page carries the search (?ra=&dec=&r=), so it can be shared.
