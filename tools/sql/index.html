SQL over the catalogs

Ask the CTAS and WorldsIndex catalogs anything with SQL. The query runs in your browser with DuckDB-WASM, reading VOParquet copies of the public exports that this site serves; only the byte ranges a query needs are downloaded.

The query engine (DuckDB-WASM 1.32.0, about 8 MB compressed) is downloaded from cdn.jsdelivr.net the first time you run a query, and DuckDB then fetches its Parquet reader from extensions.duckdb.org. Your queries are not sent anywhere. The release VOParquet files on GitHub Releases cannot be used from a browser (GitHub sends no CORS header for them), so these copies are rebuilt with every deployment.
