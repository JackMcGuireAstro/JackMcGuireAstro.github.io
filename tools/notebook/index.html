Reading the record…

The notebook reads this site’s public files with astropy: the record, its photometry or catalog values, a plot, and (for CTAS) its DataLink links. It runs in Jupyter on your computer, or in JupyterLite in your browser.

Get the notebook

Run in the JupyterLite demo ↗

The JupyterLite link opens the public JupyterLite demo (jupyterlite.github.io, run by the Jupyter project, not by this site) with the notebook’s code; the first run installs astropy and matplotlib there, which takes a minute. That demo is not version-pinned by this site. To keep a fixed copy, download the .ipynb and open it in Jupyter or upload it to any JupyterLite.
